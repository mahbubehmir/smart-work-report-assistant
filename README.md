# دستیار هوشمند ثبت و پیگیری گزارش

ربات تلگرام برای دریافت گزارش آزاد فارسی، استخراج اطلاعات با LLM، ذخیره در SQLite و ساخت خلاصه هفتگی.

## 1) نصب

Python 3.10 یا بالاتر پیشنهاد می‌شود.

```bash
python -m venv .venv
```

ویندوز:
```bash
.venv\Scripts\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

## 2) تنظیم تلگرام

در تلگرام با `@BotFather` یک ربات بسازید و توکن را در `.env` در مقدار `TELEGRAM_BOT_TOKEN` قرار دهید.

## 3) انتخاب مدل هوش مصنوعی

### گزینه A: Ollama محلی (پیش‌فرض)

مطمئن شوید Ollama در حال اجراست و مدل نصب شده است:

```bash
ollama pull qwen3:8b
```

در `.env`:
```env
LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen3:8b
```

### گزینه B: OpenAI API

در `.env`:
```env
LLM_PROVIDER=openai
OPENAI_API_KEY=کلید-واقعی-شما
OPENAI_MODEL=gpt-4o-mini
```

کلید واقعی را با دیگران به اشتراک نگذارید و فایل `.env` را در GitHub آپلود نکنید.

## 4) اجرا

```bash
python main.py
```

## 5) استفاده

- `/start` راهنما
- ارسال متن فارسی برای ثبت گزارش
- `/weekly` خلاصه هفته جاری (از دوشنبه تا یکشنبه)
- `/myreports` پنج گزارش اخیر همان کاربر

## نکات طراحی

- اگر نام در متن گزارش نباشد، ربات نام را حدس نمی‌زند و درخواست شفاف‌سازی می‌کند.
- اگر مشکلی مطرح نشده باشد، آرایه مشکلات خالی ذخیره می‌شود.
- تعداد مشکلات در خلاصه هفتگی، تعداد موارد ثبت‌شده در آرایه مشکلات است.
- تشخیص «پرتکرارترین مشکل» در نسخه پایه بر اساس عبارت‌های یکسان/تقریباً یکسان (فاصله و بزرگی حروف) است؛ برای تشخیص معنایی عبارت‌هایی مانند «API پرداخت قطع است» و «درگاه پرداخت کار نمی‌کند» می‌توان بعداً خوشه‌بندی معنایی اضافه کرد.
- در نسخه نمایشی، هر کاربر می‌تواند `/weekly` را اجرا کند. قبل از استفاده سازمانی، این دستور را به شناسه مدیران محدود کنید.
- تاریخ گزارش به صورت میلادی ISO ذخیره می‌شود تا مرتب‌سازی و محاسبه بازه زمانی ساده و دقیق باشد.
