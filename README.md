# دستیار هوشمند ثبت و پیگیری گزارش‌های کاری

یک ربات تلگرام مبتنی بر Python که گزارش‌های کاری فارسی را به زبان طبیعی دریافت می‌کند، اطلاعات مهم را با کمک مدل زبانی استخراج می‌کند و در پایگاه داده SQLite ذخیره می‌کند.

## قابلیت‌ها

- دریافت گزارش کاری فارسی بدون نیاز به قالب مشخص
- استخراج نام ثبت‌کننده، تاریخ گزارش، کارهای انجام‌شده و مشکلات
- ذخیره گزارش‌ها در پایگاه داده SQLite
- مشاهده پنج گزارش اخیر هر کاربر
- استفاده از مدل محلی Ollama یا سرویس OpenAI برای پردازش متن
- رابط کاربری تلگرام با دکمه‌های راهنما و ثبت گزارش

## فناوری‌های استفاده‌شده

- Python
- python-telegram-bot
- Ollama و مدل Qwen3
- OpenAI API (اختیاری)
- SQLite
- Requests و python-dotenv

## پیش‌نیازها

قبل از اجرا، موارد زیر باید نصب یا آماده باشند:

- Python نسخه 3.10 یا بالاتر
- Git
- یک ربات تلگرام و توکن آن از طریق `@BotFather`
- Ollama و مدل `qwen3:8b`، یا کلید معتبر OpenAI API

## نصب و راه‌اندازی در ویندوز

### 1. دریافت پروژه

در ترمینال اجرا کنید:

```bash
git clone https://github.com/mahbubehmir/smart-work-report-assistant.git
cd smart-work-report-assistant
```

### 2. ایجاد محیط مجازی

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی در Command Prompt ویندوز:

```bat
.venv\Scripts\activate
```

سپس وابستگی‌های پروژه را نصب کنید:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. تنظیم متغیرهای محیطی

در پوشه اصلی پروژه، فایل `.env` ایجاد کنید:

```env
TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen3:8b
DATABASE_PATH=reports.db
LOG_LEVEL=INFO
```

مقدار `YOUR_TELEGRAM_BOT_TOKEN` را با توکن واقعی ربات خود جایگزین کنید.

**مهم:** فایل `.env` حاوی اطلاعات محرمانه است و نباید در GitHub منتشر شود.

### 4. آماده‌سازی مدل هوش مصنوعی

برای استفاده از Ollama، ابتدا آن را نصب و اجرا کنید. سپس در ترمینال دستور زیر را اجرا کنید:

```bash
ollama pull qwen3:8b
```

مطمئن شوید سرویس Ollama در آدرس زیر در دسترس است:

```text
http://localhost:11434
```

### استفاده اختیاری از OpenAI

اگر قصد استفاده از OpenAI API را دارید، تنظیمات `.env` را به شکل زیر تغییر دهید:

```env
TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
LLM_PROVIDER=openai
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
OPENAI_MODEL=gpt-4o-mini
DATABASE_PATH=reports.db
LOG_LEVEL=INFO
```

در این حالت، به کلید معتبر OpenAI API و دسترسی اینترنت نیاز دارید.

### 5. اجرای ربات

پس از تکمیل تنظیمات، از پوشه اصلی پروژه دستور زیر را اجرا کنید:

```bash
python main.py
```

در صورت موفقیت، پیام آماده‌به‌کار بودن ربات در ترمینال نمایش داده می‌شود.

## نحوه استفاده

1. ربات تلگرام خود را باز کنید و دستور `/start` را ارسال کنید.
2. یک گزارش کاری را با زبان طبیعی فارسی بنویسید و ارسال کنید.
3. ربات اطلاعات گزارش را استخراج می‌کند و پس از اعتبارسنجی، آن را در SQLite ذخیره می‌کند.
4. برای مشاهده پنج گزارش اخیر خود، از دستور `/myreports` یا دکمه مربوط به آن استفاده کنید.
5. برای مشاهده راهنما، دستور `/help` را ارسال کنید.

### نمونه گزارش

```text
من رضا هستم. امروز بخش ورود کاربران را تکمیل کردم،
اما به دلیل نداشتن دسترسی به سرور نتوانستم
تست نهایی را انجام دهم.
```

انتظار می‌رود ربات کار انجام‌شده و مانع گزارش‌شده را استخراج و نتیجه ثبت را به کاربر نمایش دهد.

## ساختار پروژه

| فایل | کاربرد |
|---|---|
| `main.py` | نقطه ورود و راه‌اندازی ربات تلگرام |
| `config.py` | خواندن تنظیمات محیطی |
| `handlers.py` | پردازش پیام‌ها و مدیریت تعامل با کاربر |
| `services.py` | استخراج اطلاعات با مدل زبانی |
| `database.py` | ذخیره و بازیابی اطلاعات SQLite |
| `keyboards.py` | ساخت دکمه‌های رابط کاربری |
| `reports.py` | توابع آماده‌سازی گزارش و خلاصه |
| `scheduler.py` | اجزای زمان‌بندی |
| `requirements.txt` | وابستگی‌های Python |
| `.env` | تنظیمات محلی و اطلاعات محرمانه |

## نکات امنیتی

- توکن تلگرام و کلید API را در مخزن عمومی قرار ندهید.
- فایل `.env` و پایگاه داده محلی را در GitHub منتشر نکنید.
- برای استفاده سازمانی، دسترسی به گزارش‌ها و اطلاعات حساس باید متناسب با نقش کاربران کنترل شود.

## محدودیت نسخه فعلی

تابع آماده‌سازی خلاصه در `reports.py` وجود دارد، اما فرمان `/weekly` در نسخه فعلی ربات فعال نشده است. برای دسترسی به خلاصه از داخل تلگرام، باید اتصال این قابلیت در `main.py` و رابط کاربری تکمیل شود.
